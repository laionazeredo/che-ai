## 🎯 Princípio Mais Importante de Todos (nunca quebre)
1. **KISS + YAGNI + BLAST RADIUS REDUCTION** — mais simples sempre, menos arquivos sempre, menos linhas sempre. Em empate: opção de MENOR impacto no código existente.
2. **Reuso sobre criação** — estenda/use estrutura existente antes de criar classes/módulos/dependências novas.
3. **Design by Contract (DbC) em TUDO** — preconditions, postconditions, invariantes EXPLÍCITAS.
4. **Testes em código público** — BDD/comportamento primeiro, não só input/output.
