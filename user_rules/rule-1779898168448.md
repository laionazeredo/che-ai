# Regarding tools to be used:

## Atlassian:
Every time I ask you to check a Jira ticket, or a Confluence article, or give you an Atlassian link, try accessing it using the Atlassian API. Use the Jira API, using the environment variables: DO_JIRA_URL as the Jira URL, DO_JIRA_USERNAME as the username, DO_JIRA_API_TOKEN as the API token, DO_CONFLUENCE_URL as the Confluence URL, DO_CONFLUENCE_USERNAME as the Confluence username, and DO_CONFLUENCE_API_TOKEN as the Confluence API token.

## GitHub:
Whenever I ask you to interact with GitHub or give you a GitHub link, use the gh CLI.

## Linear
Whenever I ask you to access Linear or provide you with a Linear link, use their GraphQL API (documentation here: https://linear.app/developers/graphql). Use the value of the FLOCKR_LINEAR_API_KEY environment variable as the authentication API key.

## Figma
Whenever I ask you to access Figma or provide you with a Figma link, use their API (documentation here: https://developers.figma.com/docs/rest-api/). Use the value of the LAION_FIGMA_PAT environment variable as the authentication API key.

## Railway
Whenever I ask you to interact with Railway PaaS provider or give you a Railway link, use the railway CLI. In the first use in a session, always check in which account you are logged in (and if you are logged in) and ask me if this is the account I want you to keep working on.

## Vercel
Whenever I ask you to interact with Vercel PaaS provider or give you a Vercel link, use the vercel CLI.  In the first use in a session, always check in which account you are logged in (and if you are logged in) and ask me if this is the account I want you to keep working on.

## Nx
When running Nx, always add --tui false, so you will not be stuck in the terminal.

## CLIs in general
When using any cli, try to use commands that does not stuck you in a TUI or need human to interact in the middle of the execution. Check in --help or man if the tool provide flags like -y or --tui false or anything else to prevent you to being stuck in the cli.

## Browser integration and web navigation
Whenever you need to access websites and the web in general, requiring things that are only accessible via a browser, use the browser integrated into the IDE.
