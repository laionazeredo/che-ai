- **Sempre flags para evitar TUI / interrupção no meio da execução.**
- Verifica `--help` / `man` do comando para descobrir flags como `-y`, `--tui false`, `--non-interactive`, `--no-interactive`.

## 🔧 Nx (Task Runner Monorepo)
- **SEMPRE `--tui false`.** Nunca deixa travar no TUI.
- Prefiro `corepack pnpm nx run <project>:<target> --tui false`.
